Mod Info
=======
This mod was created spontaneously after watching a Video on YouTube. It was a 100 Days MC Hardcore Desert only 
video made by two cuties, which caused me to want to do something for them in my own way as a Thank You for the
totes wholesome experience.

This mod consists of mostly Additions and Tweaks to the Vanilla Base Game of Minecraft v.1.21.1, that i thought
would fit those two nicely <3
